# Image Assets Needed for SEO

## Required Images

### 1. Open Graph Image
**File:** `og-image.png`
**Dimensions:** 1200 x 630 pixels
**Format:** PNG
**Purpose:** Displayed when sharing links on Facebook, LinkedIn, etc.

**Recommended Design:**
- BhumiShop logo/wordmark
- Tagline: "Products with meaning, art and purpose"
- Bhumisparsha School branding
- Purple/gradient background (matching site theme: #667eea to #764ba2)

### 2. Twitter Card Image
**File:** `twitter-card.png`
**Dimensions:** 1200 x 600 pixels
**Format:** PNG
**Purpose:** Displayed when sharing links on Twitter

**Recommended Design:**
- Similar to OG image but optimized for Twitter's aspect ratio
- Can be the same as OG image

### 3. Logo
**File:** `logo.png`
**Dimensions:** 512 x 512 pixels (minimum)
**Format:** PNG with transparent background
**Purpose:** Used in structured data and search results

**Recommended Design:**
- Clean, simple logo
- Works on both light and dark backgrounds
- High resolution for retina displays

## Optional Images

### 4. Favicon Sizes
**Files:**
- `favicon-16x16.png`
- `favicon-32x32.png`
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `apple-touch-icon.png` (180x180px)

### 5. Screenshot
**File:** `screenshot.png`
**Dimensions:** 1280 x 720 pixels
**Purpose:** App showcase, documentation

## Color Palette Reference
- Primary gradient: #667eea to #764ba2
- Accent: #8b5cf6 (purple)
- Use these colors for consistency

## Placement
All images should be placed in: `/public/images/`
